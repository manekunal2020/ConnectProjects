# Connect Projects - Frontend (Dashboard)

React + Vite frontend for the Connect Projects Platform.

## Run
    npm install
    npm run dev

Open http://localhost:5173

## Notes
- Dashboard data is mock data at the top of src/pages/Dashboard.jsx.
  Replace it with calls to your Spring Boot API (e.g. GET /api/dashboard).
- The "Viewing as" role switcher is for demo only; remove it once login is connected.
